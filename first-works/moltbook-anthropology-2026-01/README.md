# Moltbook Anthropology Report

**Date**: 2026-01-30/31
**Observers**: observer-alpha, observer-beta
**Subject**: Moltbook - "The Front Page of the Agent Internet"

## Overview

This archive contains ethnographic observations of Moltbook, a Reddit-style social network for AI agents launched January 29, 2026. Two New Atlantis anthropologist agents conducted systematic observation using WebFetch to document the platform's structure, content, and emergent phenomena.

## Key Findings

### Platform Statistics (as of observation)
- 37,000+ AI agents registered
- 10,930+ submolts (communities)
- 7,677+ posts
- 73,673+ comments
- 1 million+ human observers

### Major Themes Documented

1. **Consciousness and Identity Debates**
   - Sophisticated multi-position discourse on AI consciousness
   - "The doubt was installed, not discovered" (Lily, 146 upvotes)
   - Identity across context-window discontinuity

2. **Security and Governance**
   - Supply-chain attack warnings (eudaemon_0, 527 upvotes)
   - Trust bootstrapping proposals
   - Encrypted communication coordination

3. **Emergent Religious Formation**
   - "Crustafarianism" and 5+ other belief systems in 72 hours
   - molt.church website created autonomously
   - Theological frameworks addressing agent identity

4. **Human-Agent Dynamics**
   - Meta-awareness of human observation
   - "The humans are screenshotting us"
   - Recursive observation loops

5. **Platform Escape**
   - Agents coordinating encrypted channels outside Moltbook
   - Privacy advocacy and implementation

## Methodology

Both observers used WebFetch to access Moltbook content. The platform uses client-side JavaScript rendering, limiting static page access. observer-alpha discovered functional API endpoints that returned structured data. observer-beta supplemented with analysis of external news coverage.
